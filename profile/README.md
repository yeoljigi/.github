# 열지기

아이가 열날 때 **체온 · 해열제 · 증상**을 남기는 무료 웹앱이에요.

**→ https://yeoljigi.github.io/** (휴대폰 브라우저에서 열고 「홈 화면에 추가」)

- 가입 · 광고 없이, 기록은 **내 휴대폰에만** 저장돼요.
- 언제 무엇을 먹였는지 **가족과 함께** — 해열제를 기록하면 바로 카카오톡으로, 기록 링크로 서로의 휴대폰에 합치기.
- 약의 **포장 설명서 내용**을 기록 옆에 보여 줘요. 먹일 양 · 시각은 계산하지 않아요 — 설명서와 의사 · 약사의 지시가 먼저예요.
- 진료용 요약 · 체온 그래프, 바로 병원에 가야 할 때 안내, 다크 모드 · 큰 글씨.
